## 📁 How to Open a Folder

### Method 1: Quick Access (Easiest)
1. On the welcome screen, click **"📁 Current Directory"** button
2. Your current folder will open immediately!

### Method 2: Open Folder Dialog
1. Click the big **"Open Folder"** button
2. In the dialog, click **"Browse Folders"**
3. Select any folder from your computer
4. Click **"Open Project"**

### Method 3: Manual Path Entry
1. Click **"Open Folder"**
2. Type a path like:
   - `.` (current directory)
   - `./frontend` (frontend folder)
   - `C:/Users/YourName/Documents/MyProject`
3. Click **"Open Project"**

## 🔧 If Something's Not Working

### IDE Won't Load
- Refresh the browser page
- Try incognito/private mode
- Clear browser cache
- Check browser console (F12) for errors

### Folder Won't Open
- Try clicking "📁 Current Directory" first
- Make sure the path exists
- Use forward slashes: `C:/Users/Name/Folder`
- Check backend connection status

### Quick Restart
If anything goes wrong:
```bash
# Stop everything (Ctrl+C in terminals)
# Then restart:
python start_ide_fixed.py
```
